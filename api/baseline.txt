package scheduler // import "github.com/faustbrian/go-scheduler/v2"

Package scheduler compiles code-defined schedules and coordinates occurrence
decisions through application-owned executors and lease stores. Construct
definitions with NewSchedule, freeze them with Compile, then use NewRunner.
Registry reads are reusable concurrently; callbacks, backend IO and downstream
side effects remain caller-owned. The core owns no retry loop, durable queue,
timezone database, administrative authentication or forced goroutine
termination.

TYPES

type Clock interface {
	// Now returns a usable instant; concurrent runner calls require a concurrency-safe clock.
	Now() time.Time
	// After returns a timer channel; runner cancellation stops waiting, not an arbitrary custom timer.
	After(time.Duration) <-chan time.Time
}
    Clock provides current time and exact-boundary timers to a Runner.

type Condition func(Context) (bool, error)
    Condition is a trusted application predicate. Conditions run in order
    until false/error, but timeout only stops waiting; a timed-out closure
    may continue. Shared closures and the occurrence maps require application
    synchronization.

type Context struct {
	// Schedule is a copied definition; callback closures are shared application state.
	Schedule Schedule
	// Now is the tick range endpoint, not necessarily callback or completion wall time.
	Now time.Time
	// Due is the scheduled physical boundary.
	Due time.Time
	// Attempt is occurrence attempt metadata; the runner starts it at one.
	Attempt int
	// Owner is the runner lease-owner identity.
	Owner string
	// Fencing is the task token when present, otherwise occurrence token or zero.
	Fencing uint64
	// IdempotencyKey identifies rollout-stable physical occurrence ownership.
	IdempotencyKey string
	// Metadata is a copied diagnostic map shared by this occurrence's conditions and executor.
	Metadata map[string]string
}
    Context carries copied schedule and ownership data to conditions/execution.
    Its exported maps are mutable and shared within this occurrence; they must
    not be changed by a still-running condition while the executor uses them.

type Event struct {
	// Type identifies the lifecycle emission boundary, not guaranteed callback completion order.
	Type EventType
	// Result classifies the decision; EventBefore uses the zero succeeded value.
	Result Result
	// Occurrence is value metadata for the physical schedule boundary.
	Occurrence Occurrence
	// Context is the originating tick context and may already be canceled when delivered.
	Context context.Context
	// Owner is the runner identity, not an authenticated principal.
	Owner string
	// Fencing is the admitted token or zero before ownership.
	Fencing uint64
	// At is the tick endpoint carried through completion, not measured callback time.
	At time.Time
	// Err is application/backend error data; the core does not redact it.
	Err error
	// Background reports the schedule option, including pre-execution failures.
	Background bool
}
    Event carries structured lifecycle metadata. Err and context values remain
    application data; no total byte cap or redaction is enforced by this record.

type EventType uint8
    EventType identifies a scheduler lifecycle boundary.

const (
	// EventBefore is emitted immediately before execution.
	EventBefore EventType = iota
	// EventSuccess is emitted after successful execution.
	EventSuccess
	// EventFailure is emitted after a failed decision or execution.
	EventFailure
	// EventSkipped is emitted for a policy-based skip.
	EventSkipped
	// EventOverlap is emitted when an active overlap lease prevents execution.
	EventOverlap
	// EventCompleted terminates every emitted lifecycle.
	EventCompleted
	// EventFinished is emitted when the runner finishes waiting for started work.
	// Timeout/heartbeat failure can leave the executor running afterward.
	EventFinished
)
func (eventType EventType) String() string
    String returns the stable lifecycle label, or unknown for an invalid value.

type Executor interface {
	// Execute must cooperate with cancellation and enforce downstream fencing/idempotency as needed.
	Execute(context.Context, Context) error
}
    Executor performs or dispatches an occurrence. Execute may run concurrently;
    failure/panic errors remain visible and may contain application-sensitive
    text. Cancellation is cooperative; the runner does not retry or forcibly
    terminate it.

type Hook func(Event)
    Hook consumes a lifecycle event in a managed callback goroutine. It must
    tolerate concurrent/reordered completion; timeouts cannot terminate it.
    Callbacks should not synchronously Drain their own runner.

type Hooks struct {
	// Before runs for EventBefore, before managed execution admission.
	Before Hook
	// Success runs for a successful runner execution/dispatch wait.
	Success Hook
	// Failure runs for a failed decision or execution wait.
	Failure Hook
	// Skipped runs for a policy skip, not an overlap event.
	Skipped Hook
	// Overlap runs when an active task lease suppresses the occurrence.
	Overlap Hook
	// Completed runs for the terminal decision event, subject to best-effort callback admission.
	Completed Hook
	// After runs for EventFinished; a timed-out executor can still be active.
	After Hook
}
    Hooks configures optional callbacks for each lifecycle boundary.

type Registry struct {
	// Has unexported fields.
}
    Registry retains copied definitions and compiled timing. Concurrent
    read-only use is supported; function closures and application dependencies
    are shared. Construct it with Compile; a nil registry is not a usable method
    receiver.

func Compile(schedules ...Schedule) (*Registry, error)
    Compile checks registry size, duplicate names, cron and locations, joining
    failures without a partial registry. Supply NewSchedule-built definitions;
    arbitrary manually mutated Schedule fields are not comprehensively
    revalidated. Slices/maps are copied, but callback closures retain their
    application state.

func (registry *Registry) ClearCache(ctx context.Context, store lease.Store) (int, error)
    ClearCache removes every currently observed task lease for schedules using
    overlap prevention. Each removal is fenced by the token returned by Inspect.
    Callers must first isolate active owners because lease removal cannot stop
    unfenced side effects already in progress.

func (registry *Registry) Due(name string, after, through time.Time) ([]Occurrence, error)
    Due selects occurrences in (after,through], applying enablement and
    inclusive date bounds. Skip selects only an exact through boundary;
    Once/CatchUp retain the newest admitted tail. ErrOccurrenceLimit returns
    no partial tail. Exhausted/nonadvancing timing can exhaust the scan cap
    instead of yielding an empty result. This is calculation only: conditions,
    pause and leases are Runner decisions.

func (registry *Registry) Next(name string, after time.Time) (time.Time, error)
    Next calculates the next timing boundary without checking Enabled or
    date bounds; use Due for execution decisions. Unknown names return
    ErrScheduleNotFound. Exhausted cron results are passed through jitter
    addition, so a nonzero offset can turn the zero sentinel into a year-one
    value rather than a future boundary.

func (registry *Registry) Overview(after time.Time) []ScheduleOverview
    Overview returns copied schedule definitions and their timing boundaries,
    sorted by schedule name. Callers supply the reference instant so inspection
    remains deterministic and can be exposed through any application surface.

func (registry *Registry) Schedules() []Schedule
    Schedules returns independent value/map/slice copies sorted by name;
    callback closures remain shared. Returned exported fields may be changed by
    the caller.

type Runner struct {
	// Has unexported fields.
}
    Runner coordinates decisions and tracks execution/callback goroutines until
    they return. Concurrent Tick/Drain use is synchronized; custom dependencies
    must support concurrency and honor contexts. Drain permanently rejects ticks
    but does not cancel Run or active work: cancel their contexts first. Backend
    deadlines require cooperation; callback/executor timeouts only stop waiting.

func NewRunner(registry *Registry, leases lease.Store, executor Executor, options ...RunnerOption) (*Runner, error)
    NewRunner requires usable dependencies and an owner, and checks advertised
    heartbeat/replacement support. Nil interfaces fail; arbitrary typed-nil
    dependencies or custom options are not universally guarded. Dependencies are
    borrowed: no backend/client/provider is closed by the runner.

func (runner *Runner) Drain(ctx context.Context) error
    Drain permanently rejects new ticks and joins decisions, executions,
    background waits and callbacks. It does not cancel them or close
    dependencies. A deadline returns ctx.Err while retained work and its waiter
    remain; repeated calls each allocate a waiter until all work returns.
    Do not call from a callback.

func (runner *Runner) Run(ctx context.Context) error
    Run waits for exact schedule boundaries and processes due occurrences.

func (runner *Runner) RunFrom(ctx context.Context, cursor time.Time) error
    RunFrom processes the bounded missed-run window strictly after cursor, then
    continues waiting for exact schedule boundaries without leaving a startup
    gap. A zero cursor is rejected because it could request an unbounded scan.

func (runner *Runner) Tick(ctx context.Context, after, through time.Time) error
    Tick processes (after,through] in sorted schedule-name order and joins
    foreground decision errors. Background completion errors use events instead.
    Each tick lazily shares one pause snapshot; concurrent ticks may duplicate
    non-leased work. Callback completion order is not event emission order.

type Schedule struct {
	// Name is the nonblank application name and registry lookup key.
	Name string
	// Version is the revision component; NewSchedule defaults it to "1".
	Version string
	// Task is the nonblank application-owned work identity.
	Task string
	// Expression is cron input, validated by Compile rather than NewSchedule.
	Expression string
	// Timezone is the explicit loader name; NewSchedule defaults to UTC.
	Timezone string
	// Identity hashes coordination, version, timing, jitter and recurring constraints.
	Identity string
	// CoordinationID hashes name, task and canonical parameters, excluding timing/version.
	CoordinationID string
	// ParameterIdentity hashes the JSON representation of admitted task parameters.
	ParameterIdentity string
	// Parameters contains JSON-copied values; callers must not mutate a compiled definition.
	Parameters map[string]any
	// Enabled controls Due/Overview and runner scheduling; Next still calculates disabled definitions.
	Enabled bool
	// Environments is an exact-match allowlist; empty permits every environment.
	Environments []string
	// DaysOfWeek filters local weekdays before missed-run selection.
	DaysOfWeek []time.Weekday
	// TimeWindows combines inclusive local windows and exclusions before jitter.
	TimeWindows []TimeWindow
	// MaintenancePolicy selects behavior when the runner is in maintenance mode.
	MaintenancePolicy MaintenancePolicy
	// Conditions contains trusted synchronous predicates; closures are not deep-copied.
	Conditions []Condition
	// StartAt is an inclusive occurrence bound; zero leaves the lower bound open.
	StartAt time.Time
	// EndAt is an inclusive occurrence bound; zero leaves the upper bound open.
	EndAt time.Time
	// Jitter bounds the stable per-revision offset to [0,Jitter); zero disables it.
	Jitter time.Duration
	// Metadata is copied diagnostic text, not authenticated or redacted by core.
	Metadata map[string]string
	// MissedRunPolicy selects exact-boundary skip, newest-only, or bounded-tail catch-up.
	MissedRunPolicy MissedRunPolicy
	// MaxCatchUp caps retained catch-up occurrences, not candidates scanned.
	MaxCatchUp int
	// OverlapPolicy selects an overlap decision; alone it does not enable the task lease.
	OverlapPolicy OverlapPolicy

package schedulerservice // import "github.com/faustbrian/go-scheduler/v2/schedulerservice"

Package schedulerservice composes a scheduler.Runner with the service lifecycle
and correlation schedule semantics.

Callers construct schedules, lease stores, executors, and facility components.
The adapter constructs and exposes the concrete runner, but it does not close
facilities itself. Facilities listed in Options start before scheduling; the
drain component is stopped before their Stop callbacks. Successful drain joins
active work, but a drain error does not prevent the service from attempting
later facility stops. Facility components retain exactly the ownership and error
policy of their own lifecycle contracts.

Every occurrence starts an independent correlation workflow by default.
CorrelationTrustedMetadata must be selected explicitly to continue trusted
correlation metadata embedded in an application-owned schedule. Retry, schedule,
lease, readiness, and business-command policy remain caller owned.

Deprecated: use github.com/faustbrian/go-scheduler/v2/adapters/service.

package valkey // import "github.com/faustbrian/go-scheduler/v2/valkey"
